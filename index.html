怎么维护这份数据？

本页为纯静态站点。日常更新只需改 data.js（鸡蛋榜 eggs、免费榜 free、套餐榜 plans、模型榜 models），保存刷新即可；改完记得更新 updatedAt。倒计时、临期预警、过期置灰由浏览器根据 end 日期自动计算。

更省事的方式：运行 node scripts/update-data.mjs --apply，脚本会巡检各厂商公告页、检查现有链接是否失效、把高置信度的新活动自动写回 data.js（带「自动收录」标记待复核），并在 reports/ 生成当日巡检报告。部署到 GitHub 后，仓库自带的 Actions 会每天定时跑一遍并自动发布。
